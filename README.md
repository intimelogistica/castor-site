# Castor Casas de Madeira — Novo Site

Novo site institucional + catálogo de modelos de casas de madeira para a Castor.

- **Domínio**: `casademadeira.com.br`
- **Stack**: Next.js 16 + React 19 + Tailwind CSS v4 + TypeScript
- **CMS**: Strapi 5.50
- **Deploy**: Vercel
- **Email**: Resend
- **Anti-spam**: Cloudflare Turnstile
- **Analytics**: GA4 + GTM + Consent Mode v2 + Vercel Analytics

## Estrutura do repositório

```
castor-site/
├── frontend/          # Aplicação Next.js
├── cms/               # CMS Strapi
├── docs/              # Planejamento e documentação
├── brand/             # Identidade visual (logo, cores, fontes)
├── planning/          # Arquitetura, keyword map, wireframes
├── research/          # Pesquisas e análises
└── scripts/           # Scripts de automação
```
