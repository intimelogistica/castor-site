# Identidade Visual Castor

Coloque nesta pasta os arquivos de identidade visual da Castor para referência no design:

- `logo/` — logo em vetor (SVG, AI, EPS) e versões PNG/JPG
- `logo/icon` — ícone/favicon
- `colors/` — paleta de cores (PDF, imagem ou arquivo com códigos hex)
- `typography/` — fontes institucionais (arquivos ou nomes das famílias)
- `photography/` — fotos de obras, modelos e showroom (originais, alta resolução)
- `brand-book.pdf` — manual de marca, se existir

## Checklist

- [ ] Logo principal (fundo claro e escuro)
- [ ] Ícone/app icon
- [ ] Paleta de cores primárias e secundárias
- [ ] Fontes institucionais
- [ ] Fotos das obras/modelos
- [ ] Depoimentos de clientes (texto + foto, se disponível)

Assim que os arquivos estiverem aqui, iniciamos a definição do design system.
